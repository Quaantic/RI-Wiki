# Game Icons

Official artwork from https://game-icons.net/, distributed through
`@iconify-json/game-icons@1.2.4` (4,133 visible icons). See `LICENSE.txt`
for the original authors and CC BY 3.0 attribution. Paths are unchanged;
the Iconify currentColor artwork is packaged as SVG symbols.

The picker stores `game-icons:fire`, for example. The renderer resolves that
name through `js/lib/game-icon-names.js` to a symbol in a local SVG file.
Keep the generated name list and all 33 SVG files together when uploading.
Existing unprefixed Lucide names retain their original artwork.

The generated SVG files are ready to use; no build or generation step is
required. The source package is available from the npm registry; the original
license is available from https://github.com/game-icons/icons.
